# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | ✅ |
| 1.x (arc2brave) | ⚠️ security fixes only if critical |

## Reporting a vulnerability

If you discover an issue involving password/cookie handling, keychain access, or secret leakage:

1. Prefer GitHub **Private vulnerability reporting** on this repository.
2. Or email the maintainer via the GitHub profile listed on the repo.

Please include:
- Affected version / commit
- Steps to reproduce
- Impact assessment

Do **not** attach real password databases or decrypted secrets to public issues.
